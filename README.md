# 청력검사 결과 쉽게보기 (PTAIA)

순음청력검사 · 임피던스(고막운동성)청력검사 결과지 PDF를 끌어다 놓으면,
**환자가 한눈에 이해하기 쉬운 형태**로 다시 보여주는 웹 프로그램입니다.

우리 병원(더원이비인후과) 결과지 양식에 맞춰 제작되었습니다. 양식이 항상 동일하므로,
PDF의 정해진 위치에서 그래프를 잘라내어 새 화면으로 재구성합니다.

## 주요 기능 (요청 사항 반영)

1. **오른쪽 / 왼쪽 표시를 크게** — 각 그래프 위에 큰 띠로 표시합니다.
2. **색상 구분** — 오른쪽은 **빨간색**, 왼쪽은 **파란색**.
3. **정상 영역 안내** — 청력도(audiogram)의 **25dB 이하 영역**에 `정상 영역` 라벨을 표시합니다.
4. **4분법 평균 dB 자동 인식(OCR)** — 검사지의 평균 dB 숫자를 읽어 **아주 크게** 표시합니다.
5. **신호등 표시** — 인식한 평균 dB의 정도에 따라 dB 숫자 **왼편에 색 신호등**을 표시합니다.
   (초록=정상 → 노랑 → 주황 → 빨강 순. 별도 설명 글자는 붙이지 않습니다.)
6. **좌우 그래프 동일 크기** — 순음청력 좌우 그래프를 같은 크기로 맞춰 보여줍니다.
7. **임피던스 3분할 보기** — `오른쪽 │ 정상 참고 │ 왼쪽` 세 그래프를 한 화면에 나란히 표시합니다.
   가운데 *정상 참고(Type A)* 그래프는 표준 정상 곡선을 프로그램이 그려 넣습니다.
8. **언어청력검사 결과 캡쳐** — 말소리 검사(SRT/WR) 결과표 부분만 잘라 보여줍니다.
9. **이명검사(Tinnitogram)** — 표의 좌/우 Pitch(Hz)·Loudness(dB)를 **OCR로 인식**해서,
   수치가 있는 쪽(=이명이 있는 쪽) 청력도를 보여주고 **그 위치에 마커**를 찍습니다.
   원본 이명검사 표도 함께 캡쳐해서 같이 보여줍니다.

> 숫자 인식(OCR)은 **Tesseract.js**를 사용하며, 결과지 양식이 항상 동일하므로
> 숫자가 적힌 칸 위치를 정확히 잘라 인식합니다.

## 실행 방법

브라우저 보안 정책상 `file://` 로 직접 열면 PDF 모듈이 동작하지 않을 수 있어,
간단한 로컬 서버로 실행하는 것을 권장합니다.

```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

그 후 첫 화면의 점선 영역에 결과지 PDF를 **끌어다 놓으면** 됩니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 (드롭 화면 + 결과 화면) |
| `styles.css` | 디자인 |
| `app.js`     | PDF 렌더링·영역 자르기·OCR·재구성 로직 |
| `vendor/`    | PDF.js + Tesseract.js(OCR) 라이브러리 (모두 오프라인 내장) |

## 개인정보 안내

- 모든 처리는 **브라우저 안에서만** 이루어지며, 검사 결과가 외부로 전송되지 않습니다.
- 환자 결과지 PDF/이미지는 저장소에 커밋되지 않습니다(`.gitignore` 처리).

## 양식이 바뀌면

결과지 양식이 바뀌면 `app.js` 상단의 좌표 상수만 조정하면 됩니다.

- `REGION` : 임피던스/언어청력/이명표 등 캡쳐 영역
- `PTA_OCR` : 4분법 평균 dB 숫자 위치
- `AUDIO_DISPLAY` : 좌우 동일 크기로 보일 오디오그램 영역
- `AUDIO_CAL` : 오디오그램 축 보정(마커 위치 계산)
- `TINNITO_CELLS` : 이명표의 Pitch/Loudness 칸 위치
